# 실행과 테스트

## 실행 방법

필요 환경은 .NET SDK 10.0입니다. Unity나 외부 NuGet 패키지는 필요하지 않습니다.

저장소 루트에서 실행합니다.

```bash
dotnet run --project Abyss.Portfolio.csproj -c Release
```

공개 샘플 검증 결과: **12 tests passed, 0 failed, 4,481 assertions**.

## 난수 테스트

[RandomnessTests.cs](../tests/RandomnessTests.cs)

- 전리품 스트림을 500회 추가 소비해도 전투·던전 스트림의 수열이 유지됩니다.
- 같은 시드는 7개 스트림 모두에서 같은 수열을 만듭니다.
- 서로 다른 지점까지 소비한 모든 스트림을 저장·복원한 뒤 다음 수열을 비교합니다.
- 단일 난수원의 스냅샷 복원과 재생성을 검증합니다.
- 정의되지 않은 스트림 이름과 잘못된 정수 범위를 거절합니다.

## 그래프 테스트

[GraphSearchTests.cs](../tests/GraphSearchTests.cs)

- 순환이 있는 그래프에서 중복 방문 없이 최단 거리를 계산합니다.
- 연결되지 않은 방과 고립된 시작점의 결과를 확인합니다.
- 시작점 또는 간선 도착 방이 없는 입력을 거절합니다.
- 최장 거리가 같은 방은 입력 순서와 관계없이 Ordinal ID 순서로 선택합니다.

## 원본 프로젝트의 검증과 관계

이 저장소의 테스트 수치는 위 독립 샘플만의 결과입니다. PDF에 소개한 83,449개 Core
assertion은 Abyss 원본 프로젝트의 규칙·콘텐츠·저장·Application 전체 검증 결과입니다.

원본 프로젝트에서는 코드 작성·리팩터링에 Codex를 활용하고, 규칙 ID 기반 테스트,
어셈블리 참조 검사, 동일 시드 실행, 저장 데이터와 동결 타임라인 비교로 변경 결과를 검증했습니다.
